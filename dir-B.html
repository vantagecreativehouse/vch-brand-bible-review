We see what matters
Erin's cinematographer DNA on the brand. Near-black grounds, one practical warm source, teal shadow fields. Letter-spacing opens, type gets room, imagery earns the frame. Reads as serious, cinematic, confident without volume.
01 / brand board · 02 / imagery rule · 03 / section mark · 04 / do and don't

Do

  • Let shadow carry the frame.
  • The practical is the only warm.
  • Keep 70% of each image in shadow.
  • Set type at a size that respects the silence.

Don't

  • Never flat lighting.
  • Never grade teal post-only — build it in-camera.
  • Never fill the frame with light.
